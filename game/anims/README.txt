Put animation files here (.fbx recommended):

  idle.fbx  walk.fbx  run.fbx  attack.fbx  die.fbx  ride.fbx   (shared by all units)
  hero_attack.fbx, sword_walk.fbx ...   (kind_name.fbx overrides for one unit type)

Best results: Mixamo character + Mixamo animations, downloaded as FBX "In Place".
Bones are matched by name (mixamorig prefix ignored), so the animation skeleton
must use the same bone names as the model.
