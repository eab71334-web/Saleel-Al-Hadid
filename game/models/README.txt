Put your 3D models here (.glb recommended, .gltf / .fbx also work):

  sword.glb    swordsman
  archer.glb   archer
  cav.glb      cavalry rider
  hero.glb     your commander
  horse.glb    horse (used by cavalry and by the hero when mounted)

Any file you do not add keeps the built-in model.
Models are scaled automatically (heights are set in game/models.gd -> HEIGHTS).
Models should face +Z (the default for glTF/Mixamo).
Animations inside the file are used automatically if their names contain
idle / walk / run / attack / die / ride.
villager.glb  villager (optional, used in Kingdom mode)
